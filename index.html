Getting Started

  1. Click the "Launch Application" button above to open the app directly
  2. Or download the nullboard.html file and open it in any modern browser
  3. Start creating your kanban boards - all data is saved locally in your browser
  4. No internet connection required after initial load!

Features

This customized version includes all original Nullboard functionality plus:

  • 150% larger UI for better readability
