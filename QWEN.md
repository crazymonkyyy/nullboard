# Nullboard Customization Project

## Project Overview

This project is a fork and customization of [Nullboard](https://github.com/apankrat/nullboard), a minimalist kanban board application. The goal is to modify the original software with specific customizations including color scheme, UI scaling, font changes, and additional features.

## Project Requirements (from SPEC.md)

Based on the SPEC.md file, the project goals include:

1. **Color Scheme**: Change default color scheme to Solarized Dark
2. **UI Scaling**: Make the UI 150% bigger than default
3. **Font Change**: Change default font to Noto Sans
4. **Keybindings Cheatsheet**: Create a keybindings reference sheet
5. **Export Feature**: Add an export to Markdown button
6. **Documentation**: Create a new README acknowledging AI usage and linking to the original project
7. **Quality Assurance**: Test all functionality
